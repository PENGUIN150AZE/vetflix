# [INFO-1] Hébergement des MP4 de clips
#          → Utilise Firebase Storage (déjà dans le projet) :
#            Console Firebase → Storage → Créer un bucket →
#            Upload le MP4 court → Copier l'URL de téléchargement publique →
#            Coller dans le champ videoUrl du CreateClipDialog (ou dans Firestore).
#          → Alternative gratuite : GitHub Releases (comme pour les films).
#            Upload le MP4 dans une release GitHub → utiliser l'URL raw.
#
# [INFO-2] C'est quoi le movieId ?
#          → Le movieId dans Firestore/clips = le champ "id" d'un CatalogItem.
#          → Cet id = le TAG de la release GitHub du film.
#            Exemple : si le film est dans la release "v1.0-minecraft",
#            son id (et donc le movieId à mettre dans clips) = "v1.0-minecraft".
#          → Pour le trouver : regarde tes releases GitHub
#            (https://github.com/PENGUIN150AZE/vetflix/releases)
#            ou affiche item.id dans les logs.

# STRUCTURE DES DOCUMENTS FIRESTORE
# =====================================
#
# Collection "clips" — document exemple :
# {
#   "movieId": "v1.0-minecraft",      ← tag GitHub de la release
#   "title": "Minecraft",              ← cleanTitle du CatalogItem
#   "videoUrl": "https://..../clip.mp4", ← URL publique Firebase Storage ou GitHub
#   "coverUrl": "https://..../coverP.png", ← URL de l'affiche (coverPUrl du film)
#   "likeCount": 0,
#   "createdAt": (Timestamp serveur),
#   "createdBy": "uid_firebase",       ← NEW : uid de l'utilisateur qui a créé
#   "approved": true                   ← NEW : modération (false = masqué)
# }
#
